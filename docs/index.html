🚀 Install in one line

No clone needed. Point your CLI at the installer:

# Gemini CLI
curl -fsSL https://raw.githubusercontent.com/JosephHampton/awesome-gemini-cli-subagents/main/install-agents.sh | bash

# Antigravity CLI (agy)
curl -fsSL https://raw.githubusercontent.com/JosephHampton/awesome-gemini-cli-subagents/main/install-agents.sh | bash -s -- --antigravity

Then just describe the work , "review this diff for security issues", and the main agent delegates to the matching specialist.

Why subagents

Each subagent has its own system prompt, its own tools and its own context window, so it stays sharp on one job instead of being average at everything. Reviewers and auditors get no file-writing tools, so they report problems instead of quietly changing your code.
