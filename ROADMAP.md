# Roadmap

Planned directions for this AI coding subagent collection. Contributions toward any of these are welcome.

## Done in v1.2.0
- Antigravity CLI support, generated and validated from a single source.
- Install a single category (`./install-agents.sh --category <name>`).
- A recipes section pairing agents for common workflows.

## Near term
- Grow each category with more high-quality AI coding subagents.
- Per-subagent example prompts and sample outputs.
- Antigravity-specific options per subagent where they help (`mainAgent`, `commandExecutionPolicy`).

## Later
- Optional MCP server suggestions per subagent where they add value.
- A marketplace entry so Antigravity CLI users can install the plugin by name.

Have an idea? Open an issue or a pull request.
